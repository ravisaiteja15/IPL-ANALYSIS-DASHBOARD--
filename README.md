# 🏏IPL-ANALYSIS-DASHBOARD

### 📌 Project Overview
This project presents a comprehensive data analysis of the Indian Premier League (IPL) from 2008 to 2025 using Power BI. It explores team performance, player statistics, match outcomes, and season-wise trends to uncover meaningful insights from IPL history.The goal is to demonstrate how data analytics and visualization can be used to understand patterns in sports and support strategic decision-making.

---
### 📊 Dataset Information
The dataset includes:
- 🗓️ Matches data (2008–2025)
- 🏏 Ball-by-ball (deliveries) data
- 👥 Teams information
- 🎯 Player performance data
- 🏟️ Venue details
---

### 🛠️ Tools & Technologies Used

- 📊 Power BI
- 🧹 Power Query (Data Cleaning & Transformation)
- 📐 DAX (Data Analysis Expressions)
- 📁 Excel / CSV files
- 📈 Data Visualization
  
---
### 📊 Key Performance Indicators (KPI's)
- 🏏 Total Matches: 2008–2025 seasons
- 🏆 Total Teams
- 🏟️ Total Venues
- 🔥 Total Sixes
- 🎯 Total Fours
- 💯 Centuries
- 🧮 Half Centuries

### 🎯Conclusion
This IPL (2008–2025) Power BI dashboard successfully transforms raw cricket data into meaningful and interactive insights across 18 seasons of the Indian Premier League.

The analysis highlights long-term trends in team performance, player contributions, and match outcomes, showing how IPL has evolved into a more data-driven and competitive tournament over the years.

Overall, this project showcases how Power BI can be used to convert complex sports data into clear, actionable insights and visual storytelling.
